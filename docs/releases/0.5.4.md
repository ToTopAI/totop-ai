# ToTop plugin 0.5.4 / Agent helper 0.3.3

Upload confirmation can take longer than 15 seconds while the platform downloads and validates a game package. The bridge previously stopped the HTTP request after 15 seconds, even though its MCP tool timeout was 120 seconds. This could report a failure after the server had successfully confirmed the upload.

This release gives MCP HTTP requests the same 120-second budget as tool calls. OAuth requests retain their 15-second limit, and caller cancellation, trusted endpoints and credential redaction remain enforced. Actual HTTP or MCP timeouts now return `bridge_request_timeout_query_status`; uncertain writes are never automatically retried.

The fix is included in the Codex, Claude Code, Cursor, DeepSeek Harness, standalone helper and desktop plugin distributions. Update the installed plugin/helper and restart its connection or application to load the new bridge. A package that the server already confirmed does not need to be uploaded again; inspect its existing state before continuing the normal review submission flow.

Validation covers delayed confirmation over OAuth and desktop transports, both timeout boundaries, cancellation, endpoint restrictions and safe timeout reporting. Distribution builds and hashes are checked before release.
